📊 Estadísticas

🎙️ Modo de grabación

En vivo: escribe mientras hablas. Estable: graba y transcribe al final con Whisper (sin "dings" en móvil).

🔑 API Key de Groq

Obtén una gratis en console.groq.com/keys. La app la guarda en IndexedDB (no se borra al limpiar caché).

🔄 Sincronización con GitHub Gist

Sync sin polling (patrón lector.html). Solo se sincroniza al abrir, al salir y con debounce de 5s tras cambios. Sin rate limit.

💾 Respaldo

Descarga un JSON con todo (notas, tareas, personas, adjuntos). Sirve para migrar a otro dispositivo o guardar copia de seguridad.

🔒 Contraseña de protección

Protege el botón "Borrar todos los datos" con una contraseña. Se guarda como hash SHA-256 (irreversible). Si la olvidas, puedes resetear con doble confirmación.

Sin contraseña configurada
⚠️ Sobre la seguridad real

Cualquier persona con acceso al archivo HTML puede ver el código. Esta contraseña solo protege contra accidentes y curiosos, no contra usuarios con conocimientos técnicos. Para seguridad real necesitarías un servidor con autenticación (Firebase, Supabase).

🗑️ Papelera (30 días)

Elementos eliminados en los últimos 30 días. Puedes restaurarlos o borrarlos definitivamente.

⚠️ Zona de peligro

Atención: Esto borra TODOS los datos locales (notas, tareas, personas, adjuntos, API key, sync). La nube NO se borra. Requiere contraseña si la configuraste.
