Di "Jarvis" para activar la captura sin tocar el botón. Consume más batería y puede fallar en móvil.

¿Cómo obtener la API key de Groq gratis?

1. Entra a console.groq.com/keys.
2. Crea una cuenta (no pide tarjeta).
3. "Create API Key" → cópiala y pégala arriba.
Límite gratis: ~30 peticiones/minuto y 14.400/día.

Privacidad y datos

Todo se guarda en localStorage de este navegador con prefijo jarvis_. Nada se sube a servidores, salvo el texto que envíes a Groq con "Analizar" o a Google Translate con "Traducir".

⚠️ Micrófono en el celular

Chrome y Brave en Android bloquean el micrófono si abres el archivo como file://. Usa la URL de GitHub Pages (HTTPS) y el permiso se pedirá una sola vez.
